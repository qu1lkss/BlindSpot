# Демонстрационные комплекты

binary содержит CSV и бинарную модель, multiclass — Parquet и модель трёх классов. В каждом комплекте 1000 синтетических наблюдений с 10 числовыми признаками. Генератор обучает линейную модель методом наименьших квадратов и классификатор ближайшего центроида на отдельных 500 синтетических наблюдениях. Обученное центрирование встроено в ONNX. Правильные классы задаются порогами суммы двух признаков. Источник и параметры генерации находятся в generate.py и паспортах.

Выберите пять файлов из одной папки в форме «Новое исследование». Генерацию можно повторить командой из корня:

```sh
docker run --rm --network none -v "$PWD/examples:/examples" blindspot-controller:0.1.0 python /examples/generate.py
```
