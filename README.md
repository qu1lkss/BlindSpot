# BlindSpot

BlindSpot — проект локального приложения для поиска слабых мест обученных моделей классификации на табличных данных. Цель — выяснить, на каких группах примеров модель ошибается чаще и как меняется её точность, если в признаках появляются пропуски или шум.

В основе проекта — три программных агента. Исследователь предлагает гипотезу, например проверить точность модели на строках с пропуском в определённом поле. Экспериментатор сравнивает прогнозы с правильными ответами. Критик оценивает результат и помогает уточнить следующую гипотезу. Например, если в выбранной группе слишком мало строк, Исследователь может расширить её границы.

Для поиска и подтверждения используются разные части данных. Условия проверки фиксируются до открытия второй части. По результатам независимой проверки можно судить, для каких условий снижение точности подтвердилось, насколько оно велико и где данных оказалось недостаточно для вывода.
