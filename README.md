# BlindSpot

Курсовой проект на тему «Разработка многоагентной системы для поиска слабых мест моделей машинного обучения».

BlindSpot предназначен для локальной диагностики обученных моделей табличной классификации. Система должна искать слабые сегменты данных, проверять устойчивость к допустимому шуму и пропускам, независимо подтверждать найденные проблемы и сохранять материалы для повторения экспериментов.

## Структура

```text
src/blindspot/
├── api.py             # Локальный API
├── controller.py      # Управление этапами и бюджетами
├── domain.py          # Сущности и состояния исследования
├── validation.py      # Проверка входных файлов
├── datasets.py        # Подготовка и разделение данных
├── adapters/          # Подключение обученных моделей
├── agents.py          # Исследователь и Критик
├── worker.py          # Выполнение экспериментов
├── isolation.py       # Защита закрытой части данных
├── statistics.py      # Метрики и статистические расчёты
├── confirmation.py    # Независимое подтверждение
├── storage.py         # SQLite и файловое хранилище
├── export.py          # Отчёты и пакет повторения
└── web/               # HTML, CSS и JavaScript интерфейса
tests/
├── unit/              # Проверки отдельных компонентов
├── integration/       # Проверки взаимодействия компонентов
└── e2e/               # Полные пользовательские сценарии
docs/                  # Архитектура, требования и разработка
examples/              # Демонстрационные материалы
.github/workflows/     # Автоматические проверки
pyproject.toml         # Настройки Python-пакета
```

Назначение компонентов описано в [архитектуре](docs/architecture.md), подготовка окружения — в [инструкции разработчика](docs/development.md).

## Техническая основа

Заданием предусмотрены Python, локальный браузерный интерфейс, отдельные вычислительные процессы, SQLite и файловое хранилище. Поисковая и подтверждающая части данных должны быть изолированы; план подтверждения фиксируется до открытия независимых данных.
