# Приём входов, 25 ноября 2026

На Linux/aarch64 в Docker тест check_validation.py загрузил через HTTP оба комплекта из examples. Для каждого протокол вернул 1000 строк и 10 признаков, для CSV два класса, для Parquet три. Повтор команды сохранил ревизию, устаревшая команда получила 409. Ошибки ID, класса, диапазона, схемы, модели, памяти и диска заблокировали старт. Семь тестов входной таблицы проверили также кодировку и точность строковых значений. Три теста черновиков проверили повтор загрузки, конфликт и неизвестную версию.

В Chrome пройдены создание, проверка, отказ с привязкой к полю, сброс результата после замены файла, открытие отчёта и конфликт ревизий. [Снимок проверки](02-inputs.png).

Воспроизведение на отдельном тестовом экземпляре:

```sh
python3 tests/e2e/check_validation.py http://127.0.0.1:18765 examples/binary examples/multiclass
node tests/e2e/check_inputs.cjs http://127.0.0.1:18765 examples/binary
```
