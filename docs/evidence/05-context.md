# Извлечение контекста F1

28 ноября 2026 года, Linux/aarch64, проект Compose blindspot-qa45. Сквозной тест tests/e2e/check_context.py прошёл через доверенный диспетчер и одноразовый поисковый контейнер без сети. Использован временной вариант синтетического набора examples/binary с 600 строками в F1 и 400 в F2.

Для версии 8a9dc244-de2b-47c6-912c-2f119a30ac33 запрос с отсутствующим словом до первого опыта вернул обязательные правила x0 и segment по точным ключам. После сохранения опыта f64ee418-615c-4ff5-b575-d7326d7d2d5f следующий запрос извлёк фрагмент этого опыта; идентификатор, число строк, accuracy и macro-F1 сверены с HTTP-протоколом. В индексе 12 источников (10 признаков, одна методика, один опыт). Записи двух запросов совпали с ответами.

Доверенный контроллер обнаружил одну контрольную строку в F2. Её ID отсутствовал в F1, текстах индекса, обеих выдачах и журнале поискового контура. Четыре модульных сценария отдельно проверили обязательные ограничения, фильтры, устойчивый порядок при равной релевантности, запрет смешивания версий и откат частичной записи. Реальный цикл с языковой моделью проверяется на этапе 8.

Для воспроизведения сначала выполните check_versions.py из протокола 03 с новым контрольным файлом, затем:

```sh
python3 tests/e2e/check_context.py http://127.0.0.1:18745 /tmp/control.json --project blindspot-qa45
```
