# Разработка

Каркас рассчитан на Python 3.11 или новее. Исполняемая бизнес-логика пока отсутствует; зависимости для вычислений и API будут добавляться вместе с соответствующими компонентами.

Создать локальное окружение:

```sh
python3 -m venv .venv
source .venv/bin/activate
```

Проверить синтаксис модулей:

```sh
python3 -m compileall -q src
```

Эта проверка не является функциональным тестированием. Автоматизация GitHub Actions выполняет её для Python 3.11 и 3.14. Совместимость будущего механизма изоляции с ОС проверяется отдельно.

Начальную страницу можно открыть из `src/blindspot/web/index.html`. Она сообщает о состоянии разработки; сервер и управление исследованием пока не реализованы.

Тесты размещаются в `tests/unit`, `tests/integration` и `tests/e2e` по мере реализации. В каждом коммите с функциональностью должны быть соответствующие проверки и обновление документации.
