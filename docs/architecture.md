# Устройство BlindSpot

Планируется локальное модульное приложение: браузерный интерфейс, управляющий процесс, отдельные вычислительные процессы, SQLite и файловое хранилище. Это описание ответственности модулей; реализация пока отсутствует.

| Модуль | Назначение |
| --- | --- |
| `api.py`, `web/` | Команды пользователя и отображение результатов |
| `validation.py`, `adapters/` | Проверка входов и подключение обученной модели |
| `domain.py` | Исследование, кандидат, эксперимент и их состояния |
| `datasets.py` | Подготовка поисковой и независимой частей |
| `controller.py` | Этапы, очередь, бюджет и остановка |
| `agents.py` | Предложение гипотез и обратная связь |
| `worker.py` | Выполнение вычислений в отдельном процессе |
| `isolation.py` | Ограничение доступа к закрытым данным |
| `statistics.py` | Метрики и статистическая оценка |
| `confirmation.py` | Фиксация плана и независимое подтверждение |
| `storage.py` | SQLite, файлы, версии и восстановление |
| `export.py` | Заключение, журнал и комплект повторения |

Порядок исследования: проверка входов → сохранение версии → базовое качество → поиск → фиксация кандидатов → независимое подтверждение → заключение и экспорт.

Поиск получает только поисковую часть. Закрытая часть открывается для подтверждения после фиксации плана. Длительные вычисления не должны блокировать интерфейс и остановку. Запись результатов координирует управляющий процесс.
